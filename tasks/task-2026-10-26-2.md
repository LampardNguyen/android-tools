# Tự kiểm tra & cài bản cập nhật từ GitHub Release

**Trạng thái:** done

## Yêu cầu
- Lấy bản mới nhất từ `https://api.github.com/repos/LampardNguyen/android-tools/releases/latest` (tham khảo Study-Loop `lib/services/github_release_update.dart`).
- Tag `vX.Y.Z` = version mới nhất, body = ghi chú, asset `.apk` đầu tiên = file tải.
- Tự kiểm tra khi mở menu (tối đa 1 lần/giờ) + nút "Kiểm tra cập nhật" thủ công.
- Có bản mới → dialog ghi chú → tải APK trong app (có tiến độ) → mở màn cài đặt hệ thống.
- Quy trình release trong CLAUDE.md thêm bước tạo GitHub Release (hỏi trước khi đăng).

- Lần đầu `release-assets.githubusercontent.com` chỉ ~43 KB/s (tải ~5 phút) — chậm tạm thời ngay sau khi đăng release. Đo lại: 12–16 MB/s; test lại trong app: bấm Cập nhật → màn cài đặt sau ~1 giây. Không phải lỗi code.

## Cách test
- Không có release / mất mạng → nút thủ công báo "Không kiểm tra được", auto-check im lặng.
- Release cùng version → "Đang là bản mới nhất".
- Release mới hơn → dialog → tải → màn cài đặt; lần đầu phải cấp quyền "Cài ứng dụng không rõ nguồn".
